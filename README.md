# The One-Line Laugh

One funny line, written for the [Make.fun bounty](https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f).

`main.py` writes the line to `/output/entry.txt`:

> I finally organised my computer files, and now I can't find anything - before, at least, everything was lost in the same place.

Run it with `python3 main.py`.
